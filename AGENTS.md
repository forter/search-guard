## Debugging Tips

1. Enable debug logging in Elasticsearch by adding the following to `elasticsearch.yml`:
   ```yaml
   logger.level: DEBUG
   ```
2. Use remote debugging with your IDE by adding the following JVM options when starting Elasticsearch:
   ```
   -agentlib:jdwp=transport=dt_socket,server=y,suspend=n,address=5005
   ```
3. Check Elasticsearch logs for Search Guard related issues:
   ```
   tail -f /path/to/elasticsearch/logs/elasticsearch.log | grep "searchguard"
   ```
